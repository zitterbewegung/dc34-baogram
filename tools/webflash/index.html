Baogram badge flasher

Irreversible: this converts the badge to developer mode

Installing a developer-signed image on a DC34 badge erases the factory light-encryption key permanently. The conference light-gene exchange with stock badges will no longer interoperate, and neither you nor the project can restore the factory state. Archive the official release first (see BAOGRAM_HARDWARE_TEST.md §2).
